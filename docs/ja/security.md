# セキュリティと脆弱性報告

[ドキュメント](README.md) · [English](../en/security.md) | [简体中文](../zh-CN/security.md) | 日本語

セキュリティ修正は最新の 0.3.x を対象とします。[GitHub の非公開脆弱性報告](https://github.com/includeno/blue-bird-cli/security/advisories/new)を使用し、公開 Issue に詳細を投稿しないでください。バージョン、影響する権限境界、架空データによる最小再現を含めます。コード、管理 URL、DB、個人タスクは添付しないでください。固定の応答期限は約束しません。

コードは協調的な機能・タグ制限です。同じ macOS アカウントで任意のコマンドを実行するエージェントは full-access や直接のデータ操作が可能です。その能力を信頼しない場合は実行サンドボックスが必要です。`bluebird start web` は所有者用入口で、エージェントコードを受け付けません。

管理画面は 127.0.0.1 のみで待ち受け、専用 URL が必要です。プロキシやトンネルで公開しないでください。完全なコードは作成直後だけ表示され、利用者が保存します。永続化するのはダイジェストと権限情報だけです。認証 DB とバックアップを保護し、紛失・漏洩時は失効させて再作成してください。変更は後続コマンドに適用され、開始済みの操作は取り消しません。

macOS アクセシビリティ、エージェントのサンドボックス、CLI 権限は別の層です。[認証](authorization.md)と[セキュリティポリシー](../../SECURITY.md)も参照してください。
