## 今回見つかり、修正した問題

- Bluebird の基本英語リソースには不足する項目があります。アプリの翻訳全体をコピーせず、開発言語の既定値で補完しました。
- フランス語の戻るボタンは `Précédent` として公開されますが、アプリの翻訳キーは `Retour` です。ポップオーバー内の安定した `plus` コントロールとナビゲーションバー上の関係から特定するようにし、構造が一意でなければ拒否します。
- メモ欄へのフォーカス移動時、Cmd+A が全文を選択しない場合がありました。追記にならないよう、置換前にネイティブの選択範囲を確認します。
- 新規タグを Return で確定するには、確実なウィンドウのアクティブ化とキーイベントのタイミング調整が必要でした。キーを押してから離すまでに処理時間を設け、作成・選択・解除・タスク削除をアプリ上で再確認しました。
- ポップオーバーのアニメーションで AX ツリーのパスが変わることがあります。ネイティブ側が未実行を確認した場合のみ更新し、一意な識別情報と選択状態を再検証します。実行結果が不明な操作は再試行しません。
