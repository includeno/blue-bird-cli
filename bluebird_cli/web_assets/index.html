CONNECT YOUR AGENT

Two ways to run the CLI.

Scoped access

Pass the code using an environment variable or --code. Keep the value out of shared logs.

export BLUEBIRD_CODE='bb_…'
bluebird auth-status
bluebird list
bluebird add 'Task' --tags 'Authorized tag'

Local owner

Explicit unrestricted access, including this authorization console.

bluebird --full-access doctor
bluebird --full-access list
bluebird start web

A precise boundary

A task needs at least one tag, and all its tags must belong to this code. Codes bind to tag IDs, so recreating a tag with the same name does not inherit access.
Bluebird CLI
